# RealtorDeIntl — Land & Houses

A premium real estate experience for discovering exceptional land, luxury homes and property investment opportunities.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Zod validation

## Getting started

```bash
npm install
npm run dev
```

The initial property catalogue uses clearly labelled demonstration listings. Replace these with verified agency inventory before launch.

See `.env.example` for optional inquiry delivery configuration.
